Veracage is a secure container protecting open encrypted volumes from the Host.

`cryptsetup` opens a LUKS or VeraCrypt volume, a root helper idmap-mounts the
decrypted filesystem so its files are presented as owned by `veracage`, a
dedicated system account, and the mount lives in a private mount namespace. Apps
run under that account, inside bubblewrap, rendered by a nested Wayland
compositor that owns the clipboard. Non-root uids are denied by ownership
through the mount.

One window with a menu bar, several volumes open side by side, text out and in
through Copy out and Paste in, files through a Shared directory, and a CLI.

First tagged release. Pre-1.0, and not independently audited.

## Install

Needs a Wayland session and Linux 5.12 or newer, for idmapped mounts.
Developed and run on Debian 12 under KDE Plasma.

```
sudo apt install ./veracage_0.7.0-1_amd64.deb
```

The attached package is built on Debian 12. From a checkout instead:
`make install`.

## Know before you use it

The isolation is one-directional: it keeps the Host out of the volume, not the
app out of the Host, so the app you launch is trusted. Root reads the plaintext.
Which volume is open is not a secret, only what is in it.

The full model is in [`docs/SECURITY.md`](docs/SECURITY.md), the mechanism in
[`docs/uid-isolation.md`](docs/uid-isolation.md), the open findings in
[`docs/known-problems.md`](docs/known-problems.md).
